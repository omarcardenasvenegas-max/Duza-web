# Sitio web DuZa

Página estática (HTML + CSS, sin dependencias). Se publica gratis en GitHub Pages, Netlify o Cloudflare Pages.

## Antes de publicar
1. En `index.html`, bloque `CONFIGURA AQUÍ` (al final): pega los enlaces de Google Play, App Store y el correo de contacto.
2. Revisa que la sección **Funciones** coincida con lo que la app hace hoy.
3. Revisa `privacidad.html`.

## Publicar en Netlify (lo más rápido, sin cuenta de GitHub)
1. Entra a https://app.netlify.com/drop
2. Arrastra la carpeta `web` completa.
3. Netlify te da una dirección tipo `duza.netlify.app` (puedes cambiar el nombre en Site settings).

## Publicar en GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)` → Save.
Queda en `https://omarcardenasvenegas-max.github.io/Duza-web/`.
